# Helena Martins Advocacia

A premium concept landing page created for a fictional law firm focused on Family and Succession Law.

This project was developed as part of my web development portfolio, with a focus on creating a professional, elegant and responsive digital presence for a legal services brand.

> **Concept Project:** Helena Martins Advocacia is a fictional brand created exclusively for portfolio and demonstration purposes. It does not represent a real lawyer or law firm.

## About the Project

The goal of this project was to design and develop a modern legal landing page that communicates professionalism, discretion and trust while avoiding the traditional visual clichés commonly associated with law firm websites.

The website presents the fictional lawyer, her practice areas, approach to client service, frequently asked questions and contact options.

## Features

## Design Direction

The visual identity was designed around a sophisticated and contemporary editorial style.

The project uses:

- Off-white backgrounds
- Deep burgundy as the primary color
- Graphite typography
- Subtle champagne accents
- Serif typography for headings
- Clean sans-serif typography for interface elements and body text

The layout prioritizes whitespace, typography and visual hierarchy to create a refined experience without relying heavily on traditional legal imagery.

## Responsive Design

The interface was designed to adapt across:

- Desktop
- Laptop
- Tablet
- Smartphone

Layouts, typography, spacing and navigation behavior are adjusted for smaller screens instead of simply scaling down the desktop version.
